# Role: Backend Engineer (fictional sample)

## Team
Platform team — owns the API and data layer.

## Responsibilities
- Build and maintain REST API endpoints.
- Own database schema changes and migrations.
- Write unit and integration tests for everything shipped.
- Review teammates' PRs within one working day.
- Join the on-call rotation from week 4.

## Owns in the codebase
- The backend/API service and its data models.
- Database seed data and migrations.

## Success after 30 days
- Local environment running without help.
- 3+ merged PRs, including one touching the data layer.
- Has reviewed at least 5 PRs.
- Can explain the request flow from API call to database and back.
